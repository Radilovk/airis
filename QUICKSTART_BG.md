# ⚡ БЪРЗ СТАРТ

## Как да отворя приложението?

### За край потребители (Без инсталация на разработка среда)

1. **Свалете архива с built версията** или клонирайте проекта
2. **Отворете папката с проекта**
3. **Отворете терминал/команден прозорец** в папката
4. **Изпълнете командите:**
   ```bash
   npm install
   npm run build
   ```
5. **Отворете файла** `dist/index.html` в браузъра си
   - Просто двоен клик на файла
   - Или десен бутон → "Отвори с" → Вашият браузър

**Готово!** 🎉 Приложението вече работи в браузъра ви!

---

## За разработчици

### Development режим (с hot reload)
```bash
npm install
npm run dev
```
Отваря се на `http://localhost:5173`

### Production build
```bash
npm run build
```
Генерира оптимизирани файлове в `dist/`

### Preview на build
```bash
npm run preview
```

## ⚠️ Важни забележки

✅ **Работи:** Можете да отворите `dist/index.html` директно в браузър
❌ **Не работи:** Не отваряйте `index.html` в root папката (този файл е template за Vite)

📁 **Файлова структура след build:**
```
dist/
├── index.html          ← Отворете ТОЗИ файл!
└── assets/
    ├── index-*.js      ← JavaScript код
    └── index-*.css     ← Стилове
```

## 🆘 Проблеми?

Ако срещнете проблеми:

1. **Уверете се, че:**
   - Имате Node.js версия 18 или по-нова
   - Сте изпълнили `npm install` преди `npm run build`
   - Отваряте `dist/index.html`, не root `index.html`

2. **Ако все още не работи:**
   - Изтрийте `node_modules/` и `dist/`
   - Изпълнете отново:
     ```bash
     npm install
     npm run build
     ```

3. **За помощ:** Отворете конзолата на браузъра (F12) и проверете за грешки

## 🌐 Споделяне

Можете да споделите приложението като:
1. Архивирате папката `dist/`
2. Изпратите архива на другите
3. Те могат да го отворят директно в браузъра си!

**Забележка:** За пълна функционалност на AI е нужна интернет връзка и API ключ.
