# ⚡ БЪРЗ СТАРТ

## Как да отворя приложението?

### За край потребители (Най-лесен начин!) ✨ БЕЗ КОНЗОЛА!

1. **Свалете/клонирайте проекта**
2. **Отворете `index.html` в root папката** (двоен клик)
3. **Готово!** 🎉 

Приложението автоматично се стартира - **НЯМА НУЖДА** от `npm install` или `npm run build`!

**Защо работи:** Проектът включва готов build в папка `dist/`, а `index.html` автоматично го зарежда.

**Алтернатива:** Можете директно да отворите `dist/index.html`

---

### За публично споделяне / хостинг

Качете **целия проект** (или само папка `dist/`) на:
- Cloudflare Pages (препоръчително)
- Netlify, Vercel, GitHub Pages
- Всеки уеб сървър

**Няма нужда от build процес!** Всичко е готово.

## За разработчици

### Development режим (с hot reload)
```bash
npm install
npm run dev
```
Отваря се на `http://localhost:5173`

### Production build
```bash
npm run build
```
Генерира оптимизирани файлове в `dist/`

### Preview на build
```bash
npm run preview
```

## ⚠️ Важни забележки

✅ **Работи:** 
- Отваряне на `index.html` в root папката (автоматично пренасочване)
- Директно отваряне на `dist/index.html` след build

📁 **Файлова структура:**
```
airis/
├── index.html          ← Launcher - отворете този файл!
├── index.dev.html      ← Template за Vite (не го отваряйте)
└── dist/
    ├── index.html      ← Built версия (може и директно)
    └── assets/
        ├── index-*.js  ← JavaScript код
        └── index-*.css ← Стилове
```

## 🆘 Проблеми?

Ако срещнете проблеми:

1. **Уверете се, че:**
   - Имате Node.js версия 18 или по-нова
   - Сте изпълнили `npm install` преди `npm run build`
   - Отваряте `index.html` (не `index.dev.html`)

2. **Ако все още не работи:**
   - Изтрийте `node_modules/` и `dist/`
   - Изпълнете отново:
     ```bash
     npm install
     npm run build
     ```

3. **За помощ:** Отворете конзолата на браузъра (F12) и проверете за грешки

## 🌐 Споделяне

Можете да споделите приложението като:
1. Архивирате папката `dist/`
2. Изпратите архива на другите
3. Те могат да го отворят директно в браузъра си!

**Забележка:** За пълна функционалност на AI е нужна интернет връзка и API ключ.
