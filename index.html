⚠️ Приложението не е built

За да стартирате приложението, моля изпълнете следните стъпки:

  1. Отворете терминал/команден прозорец в тази папка
  2. Изпълнете: npm install
  3. Изпълнете: npm run build
  4. Презаредете тази страница или отворете dist/index.html

Забележка: За разработка използвайте npm run dev
