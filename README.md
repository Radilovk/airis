## 🌟 Features

- **Health Questionnaire** - Collect biometric data and health goals
- **Iris Image Upload** - Drag & drop interface for left and right iris
- **AI Analysis** - Support for OpenAI GPT-4 and Google Gemini models
- **Interactive Report** - Circular zone visualization and radar charts
- **Personalized Recommendations** - Nutrition, supplements, and lifestyle advice
- **Admin Panel** - Configure AI models and upload iridology textbooks
- **History** - Save and review past analyses
- **Export & Share** - Download reports as text files

## 🏗️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
