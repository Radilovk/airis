# 🌐 Напълно Автономно Уеб Приложение

## За какво е това ръководство?

Това ръководство обяснява как да използвате приложението като **напълно автономен уеб сайт БЕЗ нужда от инсталация през конзола**.

## ✨ Ключови предимства

- ✅ **Без конзолни команди** - не е нужно `npm install` или `npm run build`
- ✅ **Готово за употреба** - отваряте и работи директно
- ✅ **Работи офлайн** - след първо зареждане
- ✅ **Лесно споделяне** - само копирайте файловете
- ✅ **Всички браузъри** - Chrome, Firefox, Safari, Edge

## 🚀 Как да използвате (3 начина)

### Начин 1: Директно отваряне на файл (Най-лесно)

Ако имате изтеглени файловете на компютъра си:

1. Отворете папката на проекта
2. Отворете файла `index.html` с двоен клик
3. Приложението автоматично ще стартира
4. Готово! 🎉

**Алтернативно:** Директно отворете файла `dist/index.html`

### Начин 2: Локален уеб сървър (За разработка)

Ако искате да тествате локално с уеб сървър:

#### Вариант A: С Python (за Mac/Linux)
```bash
# Влезте в папката на проекта
cd airis

# Стартирайте сървър
python3 -m http.server 8000

# Отворете в браузъра: http://localhost:8000
```

#### Вариант B: С PHP
```bash
cd airis
php -S localhost:8000
```

#### Вариант C: С VS Code Live Server
1. Инсталирайте разширението "Live Server"
2. Кликнете с десен бутон на `index.html`
3. Изберете "Open with Live Server"

### Начин 3: Публикуване в интернет (За споделяне)

За да направите приложението достъпно за всички в интернет:

#### 🌟 Cloudflare Pages (Препоръчително - Безплатно)

1. **Регистрирайте се** в [Cloudflare](https://dash.cloudflare.com/sign-up)
2. **Качете файловете:**
   - Отидете на "Workers & Pages"
   - Натиснете "Upload assets"
   - Изберете **цялата папка на проекта** (включително dist/)
   - Натиснете "Deploy site"
3. **Готово!** Вашето приложение е на адрес като: `https://airis-abc123.pages.dev`

#### Netlify (Също безплатно)

1. Отидете на [netlify.com](https://www.netlify.com)
2. Влачете цялата папка на проекта в Netlify Drop
3. Чакате 30 секунди
4. Получавате публичен URL

#### Vercel (Безплатно)

1. Отидете на [vercel.com](https://vercel.com)
2. Импортирайте проекта от GitHub или качете файловете
3. Deploy се случва автоматично
4. Получавате публичен URL

#### GitHub Pages (Безплатно)

1. Качете проекта в GitHub repository
2. Отидете в Settings → Pages
3. Изберете branch: main
4. Изберете папка: / (root)
5. Запазете
6. Приложението ще е на: `https://<username>.github.io/<repo-name>/`

## 🎯 Как работи приложението?

### Без сървър
- Всички данни се съхраняват в браузъра (localStorage)
- AI анализът се извършва чрез API (OpenAI, Gemini или Cloudflare)
- Не е нужна база данни или backend сървър

### Първо използване

1. **Отворете приложението** (чрез един от горните начини)
2. **Конфигурирайте AI:**
   - Кликнете на "Настройки" (Settings)
   - Активирайте "Използвай собствен API ключ"
   - Изберете провайдер (препоръчваме Cloudflare или Gemini за безплатно)
   - Въведете API ключ
   - Запазете

3. **Започнете анализ:**
   - Кликнете "Започни Анализ"
   - Попълнете въпросника
   - Качете снимки на ириса (ляво и дясно око)
   - Натиснете "Анализирай"
   - Изчакайте 30-60 секунди за резултат

### Получаване на безплатен API ключ

#### За Cloudflare Workers AI (Препоръчително - 10,000 безплатни заявки/ден)
1. Регистрирайте се на [Cloudflare](https://dash.cloudflare.com/sign-up)
2. Отидете на [API Tokens](https://dash.cloudflare.com/profile/api-tokens)
3. Създайте нов токен с "Edit Cloudflare Workers" права
4. Копирайте Account ID от Workers & Pages → Overview
5. В приложението:
   - Провайдер: Cloudflare Workers AI
   - Модел: `@cf/meta/llama-3.1-8b-instruct`
   - API Token: (вашият токен)
   - Account ID: (вашият account ID)

#### За Google Gemini (Безплатно - 1,500 заявки/ден)
1. Отидете на [ai.google.dev](https://ai.google.dev)
2. Кликнете "Get API key"
3. Създайте нов проект
4. Генерирайте API ключ
5. В приложението:
   - Провайдер: Google Gemini
   - Модел: `gemini-1.5-flash`
   - API Key: (вашият ключ)

#### За OpenAI (Платено - най-добро качество)
1. Отидете на [platform.openai.com](https://platform.openai.com/api-keys)
2. Създайте account и добавете пари ($5 минимум)
3. Генерирайте API ключ
4. В приложението:
   - Провайдер: OpenAI
   - Модел: `gpt-4o-mini` (най-евтино) или `gpt-4o` (най-добро)
   - API Key: (вашият ключ)

## 🔒 Сигурност и данни

### Къде се съхраняват данните?
- Всички данни са **само в браузъра** на потребителя
- API ключовете са **само локални**
- Историята на анализите е **локална**
- Никакви данни не се изпращат към сървъри на приложението

### Какво се изпраща към AI провайдерите?
- Само текстът на въпросника
- Снимките на ириса (кодирани в base64)
- Това се изпраща директно от браузъра към AI провайдера
- Приложението не съхранява или вижда тези данни

### Как да изтрия данните?
- Настройки → "Изтрий данни"
- Или изтрийте localStorage от DevTools (F12)
- Или изтрийте cookies и данни за сайта

## ❓ Често задавани въпроси

### Трябва ли ми Node.js или npm?
**НЕ!** Приложението работи без Node.js или npm. Тези инструменти са нужни само за разработка на приложението, не за използване.

### Трябва ли да правя build?
**НЕ!** Приложението идва с готов build във папката `dist/`. Просто го отваряте и работи.

### Може ли да работи офлайн?
**ДА!** След първото зареждане, приложението кешира файловете. Единственото нещо, което изисква интернет, е AI анализът.

### Защо ми иска API ключ?
За да работи AI анализът. Приложението използва вашия собствен API ключ, за да извиква AI модели. Това ви дава контрол и не изисква плащане към нас.

### Колко струва?
- **Хостинг:** Безплатен (Cloudflare, Netlify, Vercel, GitHub Pages)
- **AI анализ:**
  - Cloudflare: Безплатен (10,000/ден)
  - Gemini: Безплатен (1,500/ден)
  - OpenAI: ~$0.002-0.03 на анализ

### Могат ли да го използват повече хора едновременно?
**ДА!** Всеки потребител използва собствения си браузър и собствения си API ключ. Няма лимит на потребители.

### Как да актуализирам приложението?
1. Изтеглете новата версия от GitHub
2. Заменете старите файлове с новите
3. Запазете `localStorage` данните (те са в браузъра)

## 🎓 За разработчици

Ако искате да правите промени в приложението:

```bash
# Инсталирайте зависимости
npm install

# Стартирайте development сървър
npm run dev

# Build за production
npm run build
```

Но за **обикновени потребители** това НЕ е нужно!
