# 📖 Как да стартирам приложението?

## 🚀 Бързо стартиране (За край потребители)

Ако искате да използвате приложението директно в браузъра си без да инсталирате нищо:

### Стъпка 1: Изтеглете Build-натата версия
1. Отворете терминал/команден прозорец в папката на проекта
2. Изпълнете следната команда (ако не сте го направили вече):
   ```bash
   npm install
   npm run build
   ```
3. Това ще създаде папка `dist/` с готови за употреба файлове

### Стъпка 2: Отворете приложението
1. Отидете в папката `dist/`
2. Двоен клик на файла `index.html`
3. Приложението ще се отвори директно в браузъра ви!

**Важно:** След като направите build, можете да копирате цялата папка `dist/` където искате и да я използвате без нужда от допълнителен софтуер.

## 💻 За разработчици

### Режим на разработка (Development Mode)
За разработка на приложението използвайте:

```bash
# 1. Инсталирайте зависимостите (само първия път)
npm install

# 2. Стартирайте development сървъра
npm run dev
```

Това ще стартира Vite dev сървъра на адрес `http://localhost:5173` (или друг порт ако 5173 е зает).

### Режим на production build
За създаване на оптимизирана версия за production:

```bash
npm run build
```

Build-натите файлове ще са в папката `dist/` и ще използват относителни пътища, така че могат да работят директно от файловата система.

### Преглед на build-натата версия
За да прегледате build-натата версия с локален HTTP сървър:

```bash
npm run preview
```

## 🔧 Технически детайли

### Какво е променено?
За да може приложението да работи директно от `index.html`, конфигурацията на Vite е актуализирана да използва относителни пътища:

```typescript
// vite.config.ts
export default defineConfig({
  base: './', // Използва относителни пътища вместо абсолютни
  // ...
});
```

### Защо не работи директно от src/index.html?
Оригиналният `index.html` в root директорията е шаблон за Vite и не може да работи директно защото:
- Използва TypeScript файлове (`/src/main.tsx`)
- Има импорти на модули които трябва да бъдат компилирани
- CSS файловете трябва да бъдат процесирани от Tailwind

### Структура на файловете след build:

```
dist/
├── index.html          # Главен HTML файл - отворете този!
└── assets/
    ├── index-[hash].js # Компилиран JavaScript код
    └── index-[hash].css # Компилирани стилове
```

## ❓ Често задавани въпроси

### 1. Виждам грешка при отваряне на index.html
**Проблем:** Ако отворите `index.html` от root директорията (не от `dist/`), ще видите грешка.

**Решение:** Уверете се, че отваряте `dist/index.html`, не root `index.html`.

### 2. Промените ми не се виждат
**Проблем:** Направихте промени в кода, но не се виждат в приложението.

**Решение:** След всяка промяна трябва да направите нов build:
```bash
npm run build
```

### 3. Искам да разработвам с live reload
**Решение:** Използвайте development режима:
```bash
npm run dev
```
Това ще стартира сървър с автоматично презареждане при промени.

### 4. Има ли проблем с CORS при отваряне от файл?
**Отговор:** При използване на `file://` протокол, някои API заявки може да не работят правилно заради CORS ограничения. В такива случаи:
- Използвайте `npm run preview` за локален HTTP сървър
- Или качете приложението на уеб хостинг

## 🌐 Deployment опции

### Опция 1: Локално използване
Просто отворете `dist/index.html` в браузър - работи offline!

### Опция 2: Static hosting
Качете съдържанието на `dist/` папката на:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting
- Всеки static file hosting

### Опция 3: Споделяне
Архивирайте `dist/` папката и я споделете. Всеки може да я отвори локално.

## 📝 Забележки

- **AI функционалност:** За пълна функционалност на AI анализа е нужна интернет връзка и конфигуриран API ключ
- **Данни:** Всички данни се съхраняват локално в браузъра (localStorage/IndexedDB)
- **Актуализации:** След всяка актуализация на кода, направете нов build за да видите промените
